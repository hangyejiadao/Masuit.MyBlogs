# 微信公众号文章推送说明

博客文章一键同步到微信公众号草稿箱，检查后在公众号后台或「公众号助手」App 手动发表/群发。

**本功能按「个人订阅号」设计**，不使用服务号才有的能力（模板消息、客服消息群发等）。
不要把它当成服务号来用：个人订阅号的接口权限、群发次数和文章展现方式都和服务号不一样，
下面写清楚了。

## 一、个人订阅号能做什么、不能做什么

| 能力 | 个人订阅号 | 说明 |
| --- | --- | --- |
| 拿 access_token | ✅ | AppID + AppSecret |
| 图片上传（uploadimg） | ✅ | 正文图片先传微信再替换地址 |
| 永久素材（add_material） | ✅ | 封面图上传成永久素材 |
| 新建草稿（draft/add） | ✅ | **本功能的主流程**：文章进草稿箱 |
| 提交发表（freepublish/submit） | ❌（48001） | 自 2025 年 7 月起，微信已回收个人主体账号的发布接口权限；调了会报 48001，草稿不受影响，需手动发表 |
| 群发接口（message/mass） | ❌（本功能不用） | 群发在公众号后台手动操作 |

**发表和群发是两回事，别混用：**

- **发表**（freepublish）：文章上线，生成永久链接，可被搜一搜/推荐抓取，出现在公众号的「发表记录」里。**不推送给粉丝，不占用每天 1 次的群发次数。**
- **群发**（后台手动）：把文章推送到粉丝的微信里。订阅号的文章**折叠在粉丝的「订阅号消息」列表里**，不会像服务号那样以消息通知形式单独推送。**订阅号每天只能群发 1 次，一次最多 8 篇文章。**

所以实际流程是：博客点「同步到公众号」→ 文章进公众号草稿箱 → 你在公众号后台或手机「公众号助手」App 打开草稿检查 → 点「发表」（只上线，不推送）或「群发」（推送给粉丝，消耗当天 1 次机会）。

## 二、准备工作：拿 AppID、AppSecret，配 IP 白名单

1. 登录微信公众平台 https://mp.weixin.qq.com（个人订阅号的管理员微信扫码）。
2. 左侧菜单「设置与开发」→「基本配置」，记下 **AppID（开发者ID）**和 **AppSecret（开发者密码）**。
   AppSecret 只显示一次，重置后旧的立即失效，记下来就不要再重置。
3. 同一页的 **IP 白名单**：把博客服务器的**出口公网 IP**加进去，否则拿 access_token 会报 40164。
   家里宽带是动态 IP 的话，IP 变了就要重新加；建议把博客跑在固定 IP 的服务器上。
4. 不需要配服务器回调地址（本功能不接微信的事件推送，只主动调接口）。

## 三、配置（appsettings.json）

在服务器的 `appsettings.json` 里填 `WeChatMp` 一节（仓库里只有占位值）：

```json
"WeChatMp": {
    "Enabled": false,              // 是否启用推送；true 且 AppId/AppSecret 都填了才启用
    "AppId": "",                   // 公众号的 AppID
    "AppSecret": "",               // 公众号的 AppSecret，只能填服务器上的这份配置，严禁提交真实密钥到仓库
    "AutoPublish": false,          // 建草稿后是否自动提交发表。默认 false 只进草稿箱；
                                   // true 会调 freepublish/submit，但个人订阅号自 2025 年 7 月起已被回收该权限，
                                   // 会报 48001（草稿仍保留、可手动发表），只有企业主体已认证的账号能调通
    "DefaultThumbMediaId": "",     // 默认封面永久素材 media_id（可选）。文章里没有图片、又没填这里时推送会失败；
                                   // 封面素材先在公众号后台「素材管理 - 图片」上传，再用素材列表拿到 media_id
    "ApiBaseUrl": "https://api.weixin.qq.com"
}
```

**密钥安全**：AppSecret 只填服务器上的配置文件，**绝不要提交到 Git、不要发到聊天记录、不要写进代码注释**。
换服务器时重新填一份；怀疑泄露时去公众号后台重置 AppSecret 再更新配置。

## 四、使用方法

推送是**手动触发**的，不会自动群发：

1. **文章列表页**：已发表的文章每行多一个绿色发送图标按钮，点它 → 确认框 → 「确认同步」。
   按钮只在推送通道已配置时显示，未配置时不显示。
2. **写文章页**：编辑已发布的文章时，「发布文章」按钮旁边有「同步到公众号」按钮，流程同上。
3. 确认框里有个「同时提交发表」复选框：只有配置 `AutoPublish=true` 时可选；个人订阅号勾了也会报 48001，
   草稿不受影响，提示里会写明去后台手动发表。
4. 推送成功后提示会给草稿的 `media_id`；个别正文图片上传失败时会有单独的警告提示（图片保留原链接，
   微信里可能不显示，可改图后重新推送）。
5. **重复推送同一篇文章会产生一条新记录**，旧记录保留供追溯；草稿箱里会出现多份草稿，发表前请认准最新的
   `media_id`。建议一篇文章只推送一次，改动后重新推送前先在草稿箱删掉旧草稿。

### 推送状态

每次推送产生一条 `WeChatMpPushRecord` 记录（数据库表 `WeChatMpPushRecord`），状态有四种：

| 状态 | 含义 |
| --- | --- |
| 草稿已创建 | 文章已进草稿箱，等手动发表/群发（个人订阅号的正常终态） |
| 发表中 | 已调 freepublish/submit 提交发表，微信异步审核中 |
| 已发表 | freepublish/get 查到发表成功，记录里有文章链接 |
| 推送失败 | 建草稿或提交发表时微信返回错误，原因写在记录的 ErrorMessage 里 |

「发表中」的记录可调 `POST /WeChatMp/RefreshStatus?id={记录Id}` 查一次发表状态；
查到已发表后记录里会保存微信返回的文章链接。

## 五、内容转换规则（博客文章 → 微信图文）

| 博客侧 | 微信侧 |
| --- | --- |
| Markdown 文章 | 先用 Markdig 转 HTML，再按以下规则清洗 |
| Word/富文本（HTML）文章 | 直接按以下规则清洗 |
| 标题 | 原样使用，超过 64 字截断 |
| 摘要（digest） | 正文纯文本去空白后截取 120 字；正文为空时不填，微信用正文开头自动生成 |
| 作者 | 用文章的 Author 字段 |
| 原文链接（content_source_url） | 博客原文地址（`/Post/Details/{id}`），读者点「阅读原文」跳转 |

**标签处理**（微信编辑器只接受部分 HTML）：

- **整段删除**（含内容）：`script`、`style`、`iframe`、`video`、`audio`、`source`、`form`、`input`、
  `button`、`select`、`textarea`、`link`、`meta`、`object`、`embed`、`canvas`、`svg`、`noscript`、`template`。
  视频、音频、表单、互动组件微信图文不支持，删了不会留空壳。
- **只拆标签、保留文字**：`figure`、`figcaption`、`font`、`main`、`article`、`aside`、`header`、`footer`、
  `nav`、`details`、`summary` 等结构性标签。
- **保留**：`p`、`h1~h6`、`strong`/`b`、`em`/`i`、`u`、`s`、`ul`/`ol`/`li`、`blockquote`、`a`、`img`、
  `br`、`hr`、`span`、`section`、`div`、`table`/`thead`/`tbody`/`tr`/`td`/`th`、`code`、`pre`、`sub`、`sup`。
- **属性**：事件属性（`on*`）、`data-*`、`class`、`id` 一律去掉；只保留 `style`（行内样式）、链接的 `href`、
  图片的 `src`/`alt`、表格的 `colspan`/`rowspan`。`javascript:` 开头的链接去掉 `href` 只留文字。
- **样式限制**：微信只认行内样式，不支持外联样式表和 `<style>`；复杂排版（多栏、浮动、定位）在微信里
  可能错乱，发布前请在草稿箱预览确认。代码块、表格建议先预览。

**图片处理**：

- 正文图片逐张下载后调 `media/uploadimg` 上传成微信素材，正文里的地址替换成微信地址；
  已经是微信地址（`mmbiz.qpic.cn`）的图片不再重复上传。
- 支持 `data:` 图片（编辑器粘贴的图片）和相对地址（按站点域名补全）。
- 单张图片超过 10MB、下载超时（15 秒）、不是图片时跳过该图并给出警告，**不阻断推送**，
  图片保留原链接（微信里可能不显示）。
- **封面**：优先用文章第一张图上传永久素材（`material/add_material?type=image`）做封面；
  文章没图片、或封面上传失败时用配置的 `DefaultThumbMediaId`；两者都没有时推送失败并提示加图或配默认封面。
  微信图文必须有封面图，没有封面建不了草稿。

## 六、常见错误

| 错误 | 原因和处理 |
| --- | --- |
| 推送未启用 / 按钮不显示 | `Enabled` 不是 true，或 AppId/AppSecret 没填 |
| 40013 AppID 无效 | 配置里的 AppId 与公众号后台不一致 |
| 40125 AppSecret 无效 | AppSecret 错了或被重置过，去后台重新获取后更新配置 |
| 40164 IP 不在白名单 | 把服务器出口 IP 加进公众号后台「开发 - 基本配置 - IP 白名单」 |
| 40001/42001 token 无效或过期 | 服务已自动清缓存、换 token 重试一次；仍失败请检查凭据 |
| 45009 调用频率超限 | 今日接口调用次数用完，明天再试（每月有 10 次清零机会） |
| 48001 没有权限（发表环节） | **个人订阅号的正常情况**：自 2025 年 7 月起个人账号没有发布接口权限；草稿已保留，去公众号后台或「公众号助手」App 手动发表/群发 |
| 48001 没有权限（建草稿环节） | 公众号没开通草稿接口权限；个人订阅号一般可用，持续报错请在公众号后台检查接口权限设置 |
| 40007 media_id 不合法 | 封面用了草稿 media_id；封面必须用永久素材的 media_id |
| 这篇文章没有图片、也没有配置默认封面 | 加一张图片，或配 `DefaultThumbMediaId` |
| 这篇文章还没发布 | 只有已发布的文章能推送；先发布文章再同步 |

## 七、接口清单（后端）

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/WeChatMp/GetStatus` | GET | 推送通道状态（启用、已配置、自动发表开关） |
| `/WeChatMp/Push?id={文章Id}&publish={true/false}` | POST | 推送一篇文章（建草稿，可选自动发表）；正文图片多时可能耗时几十秒，前端超时放宽到 3 分钟 |
| `/WeChatMp/GetRecord?id={文章Id}` | GET | 文章最近一次推送记录 |
| `/WeChatMp/RefreshStatus?id={记录Id}` | POST | 查「发表中」记录的发表状态 |

以上接口都要管理员登录（`[MyAuthorize]`）。

- `src/Masuit.MyBlogs.Core/Infrastructure/DataContext.cs`、`Infrastructure/Repository/Interface/IBaseRepository.cs`、`Infrastructure/Repository/Repositories.cs`：加推送记录的 DbSet 和仓储

SDK 的体量和学习成本不划算；直接调接口依赖少、行为透明，token 缓存与重试都在服务里做了。
