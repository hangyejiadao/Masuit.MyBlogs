# 应用与授权（License）管理说明

后台功能，仅管理员登录后可访问，入口地址：

- 授权管理：`/License/Index`
- 应用管理：`/License/Applications`
- 客户管理：`/License/Customers`

三个页面顶部可互相切换。

## 功能概览

1. **应用管理**：维护受授权管理的应用（名称、应用标识 AppKey、说明）。应用标识全局唯一，留空自动生成。
2. **客户管理**：维护客户（名称、联系人、邮箱、电话、备注）。邮箱用于接收授权到期提醒，请务必填对。
3. **授权管理**：给「应用 + 客户」签发授权（License），包含授权码（留空自动生成 `LIC-XXXXXX-…` 形式）、生效日期、到期日期。列表按到期时间排序，并标注状态：正常 / 剩 N 天（30 天内）/ 已过期。
4. **续期**：列表中点「续期1年」，从当前到期日（已过期则从今天）顺延 12 个月；也可以点「编辑」直接改到期日。续期或改到期日后，到期提醒档位自动重置，会按新期限重新提醒。
5. **删除保护**：应用或客户名下还有授权时不能删除，需先删除相关授权。

## 到期邮件提醒

- 系统每天上午 9 点（服务器本地时间）自动检查一次，由 Hangfire 定时任务 `SendLicenseExpiryReminders` 执行。
- 提醒档位：在到期前 **30 天、15 天、7 天、1 天** 以及 **到期当天**，各给客户邮箱发送一封提醒邮件；每个档位只发一次，不会每天重复打扰。
- 客户未填写邮箱的授权会被跳过（记入日志）。
- 授权列表中的「立即提醒」可以随时手动给客户补发一封（用于测试邮箱是否可达），发送后列表会显示上次提醒时间。
- 邮件发件通道沿用站点现有的邮件配置（系统设置中的邮件服务器），提醒邮件标题形如「授权即将到期提醒（剩余 7 天）」。

## 数据表

随 EF 迁移 `AddApplicationLicense` 自动创建三张表：`ApplicationInfo`（应用）、`Customer`（客户）、`AppLicense`（授权，含上次提醒档位 `LastReminderStage` 与时间 `LastReminderAt`）。
