# 应用与授权（License）管理说明

后台功能，仅管理员登录后可访问。入口在新版后台（Vue）左侧菜单「授权管理」下：

- 应用管理
- License 管理

旧版 Razor 页面仍可直达：授权管理 `/License/Index`、应用管理 `/License/Applications`，两页顶部可互相切换。

被授权的「客户」不单独维护，直接来自「用户管理」中的普通用户（非管理员账号）。

## 功能概览

1. **应用管理**：维护受授权管理的应用（名称、应用标识 AppKey、说明、版本号、安装包下载地址）。应用标识全局唯一，留空自动生成。版本号与安装包地址先只存字段（安装包文件由外部托管，页面填下载地址），供后续版本校验/分发使用。
2. **价格方案**：每个应用可配多个价格方案（应用管理页点「价格方案」维护）：方案名（如「年版」）、价格（元）、有效天数、排序。**有效天数填 0 表示永久**。方案被已有授权引用时不能删除。
3. **授权管理**：给「应用 + 用户」签发授权（License），包含授权码（留空时自动生成：以「用户邮箱 + 当前毫秒时间戳 + 随机数」为原文做 SHA256 的 64 位十六进制串，生成时查库查重并有唯一索引兜底，并发签发不重复）、生效日期、到期日期。签发时可**选价格方案**：选了方案，成交价按方案价记快照（方案事后改价不影响已签发授权），到期日由「生效日 + 方案天数」自动得出（永久方案按生效日 + 100 年落库，列表状态显示「永久」），表单里填的到期日被忽略；不选方案则按表单日期手工签发。列表按到期时间排序，并标注状态：正常 / 剩 N 天（30 天内）/ 已过期 / 永久。
4. **续期**：续期弹窗选择月数（默认 12），从当前到期日（已过期则从今天）顺延；也可以点「编辑」直接改到期日。续期或改到期日后，到期提醒档位自动重置，会按新期限重新提醒。
5. **删除保护**：应用名下还有授权时不能删除，需先删除相关授权；价格方案被授权引用时不能删除，需先删除或改绑相关授权。

## 到期邮件提醒

- 系统每天上午 9 点（服务器本地时间）自动检查一次，由 Hangfire 定时任务 `SendLicenseExpiryReminders` 执行。
- 提醒档位：在到期前 **30 天、15 天、7 天、1 天** 以及 **到期当天**，各给被授权用户的邮箱发送一封提醒邮件；每个档位只发一次，不会每天重复打扰。
- 用户未填写邮箱的授权会被跳过（记入日志）。
- 授权列表中的「发提醒」可以随时手动给该用户补发一封（用于测试邮箱是否可达），发送后会更新上次提醒时间。
- 邮件发件通道沿用站点现有的邮件配置（系统设置中的邮件服务器），提醒邮件标题形如「授权即将到期提醒（剩余 7 天）」。

## 数据表

- `ApplicationInfo`（应用，含版本号 `Version` 与安装包地址 `PackageUrl`）、`AppLicense`（授权，含上次提醒档位 `LastReminderStage` 与时间 `LastReminderAt`），随 EF 迁移 `AddApplicationLicense` 创建。
- 授权通过 `UserInfoId` 绑定博客用户；原独立客户表 `Customer` 已随迁移 `LicenseBindBlogUser` 删除。
- `AppPricePlan`（价格方案）随迁移 `AddAppPricePlans` 创建；同一迁移给 `AppLicense` 加了可空的 `PricePlanId`（引用方案）与 `PaidPrice`（成交价快照），给 `ApplicationInfo` 加了 `Version`、`PackageUrl` 两列。
