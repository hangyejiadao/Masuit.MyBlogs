# 第三方单点登录（GitHub / Google）使用说明

本站支持使用 GitHub 或 Google 账号单点登录，首次登录会自动注册本站账号并绑定，之后与账号密码登录完全等效。评论功能仅对已登录用户开放，未登录访客只能浏览评论。

## 一、创建 OAuth 应用

### GitHub

1. 打开 GitHub → Settings → Developer settings → OAuth Apps → New OAuth App。
2. Homepage URL 填博客首页地址，如 `https://blog.example.com`。
3. Authorization callback URL 填：`https://blog.example.com/signin-github`（注意必须是 https，域名与实际访问域名一致）。
4. 创建后记录 Client ID，并在 Client secrets 中生成一个 Client Secret。

### Google

1. 打开 Google Cloud Console → APIs 和服务 → 凭据 → 创建凭据 → OAuth 客户端 ID，应用类型选「Web 应用」（首次使用需先配置 OAuth 同意屏幕）。
2. 「已获授权的重定向 URI」填：`https://blog.example.com/signin-google`。
3. 创建后记录客户端 ID 和客户端密钥。

## 二、填写服务器配置

在 `appsettings.json` 的 `OAuth` 节中填入凭据（两个都填的平台才会启用，留空的平台不显示登录入口，也不会影响站点启动）：

```json
"OAuth": {
    "GitHub": {
        "ClientId": "你的 GitHub ClientId",
        "ClientSecret": "你的 GitHub ClientSecret"
    },
    "Google": {
        "ClientId": "你的 Google ClientId",
        "ClientSecret": "你的 Google ClientSecret"
    }
}
```

修改后重启站点生效（配置支持热重载绑定，但认证方案在启动时注册，仍建议重启）。

## 三、使用方式与规则

- 登录入口：登录页底部「或使用第三方账号登录」区域，以及文章评论区未登录时的登录提示按钮。
- 登录成功后自动回到登录前的页面。
- 自动注册规则：优先按第三方邮箱匹配已有本站账号并自动绑定（同一邮箱在本站已有账号时不会重复建号）；没有可匹配账号时新建账号，用户名为「平台_登录名」，昵称和头像取自第三方平台，密码为随机值（该账号如需用密码登录，可走找回/重置密码流程）。
- 一个本站账号可以同时绑定 GitHub 和 Google（用相同邮箱登录两个平台会自动归到同一账号）。
- 第三方未返回邮箱时（如 GitHub 隐藏邮箱），系统会用占位邮箱建号，不影响登录与评论，但收不到评论回复的邮件通知；建议在 GitHub 中公开邮箱或授权时允许读取邮箱（本站已默认请求 `user:email` 范围）。
- 数据库新增表 `ExternalLogin` 保存绑定关系（随 EF 迁移自动创建）；`LoginType` 新增 `GitHub`、`Google` 两种登录记录类型。
