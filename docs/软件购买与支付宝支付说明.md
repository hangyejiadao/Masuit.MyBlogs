# 软件购买与支付宝支付说明

## 功能概览

- 前台商店（主站 Razor，入口：顶部导航「软件购买」→ `/Store`）
  - 列表页 `/Store`：展示全部可用应用（名称、说明、方案数、最低价）。
  - 详情页 `/Store/Detail/{应用Id}`：应用信息、版本与下载链接、价格方案单选（选中即显示应付金额，金额 = 方案价格，不做折算），「立即购买」创建订单并进入支付页。
  - 支付页 `/Store/Pay/{订单Id}`：订单信息 + 支付宝支付按钮；未配置支付通道时显示「支付通道尚未配置，请联系管理员」。
  - 支付结果页 `/Store/Result?out_trade_no={订单号}`：支付宝同步回跳落地页，只展示状态，不在此处改订单/发授权。
  - 「我的订单」`/Store/MyOrders`（需登录，导航里登录后可见）：本人订单列表，已支付订单可查看授权码与到期时间；待支付订单可继续支付。
- 后台（Vue，授权管理组 →「订单管理」）
  - 分页列表 + 关键字（订单号/用户名/昵称/邮箱/应用名/支付宝交易号）+ 状态筛选；详情弹窗含支付宝交易号与发放的授权；可「关闭订单」（仅待支付可关）。
  - 后台**不提供**手动改已支付、手动发放授权的操作——授权只由支付宝异步通知自动发放，避免绕过支付。

## 购买要求登录

购买、支付、查看订单都要求前台登录（订单与授权都要绑定博客用户）。未登录点「立即购买」会跳到登录页（`/Passport/Login?from=/Store`），登录后返回商店重新下单即可。

## 订单与状态流转

实体 `AppOrder`（迁移 `AddAppOrders`），下单时把方案名/价格/有效天数做快照，后续改方案不影响历史订单。订单号 = 下单时间（yyyyMMddHHmmss）+ 6 位随机数，唯一索引。

```
创建订单（选方案） ──► 待支付(Pending=0)
                        ├─ 支付宝异步通知验签+金额校验通过 ──► 已支付(Paid=1)：记 PaidAt（取支付宝付款时间）、AlipayTradeNo，自动发放授权并回填 IssuedLicenseId
                        └─ 后台关闭 ──► 已关闭(Closed=2)：不可再支付
```

自动发放的授权与后台手工签发规则一致：用户 = 下单用户，生效 = 支付当天，到期 = 生效 + 方案有效天数（0 天按既有口径 +100 年，页面显示「永久」），PaidPrice = 方案价快照，授权码由现有 `SHA256 + 唯一性校验` 逻辑生成。

## 支付宝对接（电脑网站支付 alipay.trade.page.pay）

使用 Essensoft.Paylinks.Alipay v5（`Essensoft.Paylinks.Alipay.Client/.Payments/.Mvc` 5.0.4）。

- 支付页点「支付宝支付」→ 服务端用 `AlipayTradePagePayRequest` 生成带 RSA2 签名的自动提交表单（product_code = FAST_INSTANT_TRADE_PAY）→ 浏览器跳支付宝收银台。
- 异步通知 `POST /Store/AlipayNotify`（匿名 + 绕过防火墙，支付宝服务器直连）：SDK 内部验签 → 校验 AppId、订单号、金额（须与订单 Amount 一致）、交易状态（TRADE_SUCCESS / TRADE_FINISHED）→ Redis 分布式锁防并发 + 订单状态幂等（已支付直接返回 success，不重复发授权）→ 置已支付并自动发授权 → 回 `success`；任何校验失败回 `failure`，支付宝会按其策略重试。
  - 发授权带可恢复设计：发授权与回填订单在同一事务边界内完成；若进程在两者之间中断，重试通知会按订单备注找回已发授权并回填，不会重复发放。
- 同步回跳 `GET /Store/Result?out_trade_no=...`：仅展示，不作为支付成功依据（以异步通知为准）。

### 配置（凭据由管理员填写，勿把真实密钥提交进仓库或发到聊天里）

服务器上的 `appsettings.json`（宿主机 `/home/work/myblogs/conf/appsettings.json`，改后重启容器）新增 `Alipay` 节：

```json
"Alipay": {
  "Enabled": true,
  "AppId": "支付宝开放平台应用的 AppId",
  "PrivateKey": "商户应用私钥（PKCS8，与开放平台上传的应用公钥对应）",
  "AlipayPublicKey": "支付宝公钥（开放平台「接口加签方式」处获取，不是应用公钥）",
  "Gateway": "https://openapi.alipay.com/gateway.do",
  "NotifyUrl": "",
  "ReturnUrl": ""
}
```

- `NotifyUrl` / `ReturnUrl` 留空时默认按当前请求拼 `{站点}/Store/AlipayNotify` 与 `{站点}/Store/Result`；站点域名固定时建议显式填写为 `https://hangyejiadao.vip/Store/AlipayNotify` 与 `https://hangyejiadao.vip/Store/Result`。
- 沙箱联调把 `Gateway` 改为 `https://openapi-sandbox.dl.alipaydev.com/gateway.do` 并换成沙箱应用的凭据。
- 支付宝开放平台侧需为该应用签约开通「电脑网站支付」产品。

### 未配置时的行为

`Enabled=false` 或 AppId/私钥/公钥任一为空即视为未配置：

- 支付页显示「支付通道尚未配置，请联系管理员」，订单保留为待支付；
- 点支付不会发起任何跳转，**绝不会**把订单改成已支付或发放授权；
- 异步通知端点在未配置时直接返回 `failure`。
